# KÝMARE — Greek Cuisine & After Dark

Website for a fictional modern Greek restaurant and late-night venue in New York City, built with the Next.js App Router. Content is kept in a typed data module (`app/site-data.ts`) and rendered through reusable components.

**Stack:** Next.js 16, React 19, TypeScript, ESLint

## Run locally

```bash
npm install
npm run dev
```
